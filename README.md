Velkommen til develop-branchen! Her kan dere merge så mye dere vil. Dette er essensielt en "unstable" versjon av main/MVP, hvor vi pusher mange ting vi jobber med her. For mer informasjon, sjekk GitFlow.
Husk å "merge" via pull requests! git merge eller rebase funker uten pull requests, men de kommer uten commit historien! Da vet vi ikke hvem som har gjort hva og hvem som har peiling på ting.
![GitFlow](gitflow-1.png)
Man skal i utgangspunktet la nye brancher ta utgangspunkt i denne branchen.
Hvis dere sliter med litt dependencies, prøv å synkronisere Gradle filene!
